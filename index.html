What you are actually buying

The claude.com pricing page splits consumer plans three ways. Free costs nothing and covers chat on web, iOS, Android and desktop, code generation, web search, memory across conversations, file creation and code execution, plus connectors through remote MCP. Pro is listed at seventeen dollars a month with the annual discount, billed as two hundred dollars up front, or twenty dollars if you pay monthly, and its feature list explicitly includes Claude Code. Max starts at one hundred dollars a month and is sold as five to twenty times the usage of Pro, with higher output limits and priority access at busy times. So there is no separate Claude Code purchase to make on that page. Pick the tier whose usage ceiling matches how much you intend to lean on it, and remember the site's own footnote that usage limits apply and prices can change.

Claude Code setup before you install anything

Decide what you will point it at first. The single biggest difference between people who keep this tool and people who cancel after a month is whether the first session had a real, bounded task in a repository they know well. A vague prompt against an unfamiliar codebase produces output nobody can evaluate, and the natural conclusion is that the tool is unreliable rather than that the brief was. Pick something you could have done yourself in an hour: a test you have been avoiding, a migration across a handful of files, a bug with a reproduction. You will be able to judge the result instantly, which is the entire point of the first hour.

Free versus Pro, honestly

Free is genuinely useful for the conversational half of the work. You can paste code in, get it explained, generate a script, search the web and keep memory across conversations. What it does not carry, according to the plan list, is Claude Code itself. If your workflow is reading, thinking and pasting, stay free and spend nothing. If your workflow is editing files in place across a project, that is the line where the subscription starts to pay for itself, and it is worth being honest with yourself about which one you do all day. Many people describe themselves as the second and behave like the first, which is an expensive kind of optimism when it renews every month.

Where Max makes sense

Anthropic describes Max as five to twenty times more usage than Pro, from one hundred dollars a month, with higher output limits, early access to advanced features and priority access at high traffic times. That is a bandwidth upgrade, not a capability upgrade, and the honest test is whether you have already been stopped by limits on Pro. Upgrading before you hit a wall is buying a queue position you have not needed yet. Run Pro for a full working month, notice how often you get throttled mid-task, and let that number make the decision. Prices and plans are subject to change at Anthropic's discretion, as the pricing page itself says, so recheck before committing to an annual payment.

A first hour that tells you the truth

  1. Choose the tier by usage, not features
    Pro is the entry point that lists Claude Code. Start there rather than at Max, because Max buys throughput you have not proven you need yet.
  2. Open a repo you know cold
    Familiar code is the only place you can judge output quickly. An unfamiliar codebase turns every review into a research project and teaches you nothing about the tool.
  3. Give it one bounded job
    One bug with a reproduction, or one small refactor. Read every changed line. This is the session that decides whether the subscription stays on your card.
  4. Watch where you hit the ceiling
    Note when limits interrupt real work. That log, not a feature comparison, is what should drive any later upgrade decision.

FAQ

Which plan do I need for Claude Code setup?

Per the official plan list, Claude Code appears in the Pro feature set and in everything above it, not in Free. Pro is shown at seventeen dollars a month with the annual discount, two hundred billed up front, or twenty dollars month to month. Max starts at one hundred and is sold on usage headroom rather than extra capability.

Is there a free version?

There is a free Claude tier, and it covers a lot: chat across platforms, code generation, web search, memory, file creation and code execution. What the published list does not include at that tier is Claude Code itself, so if the terminal workflow is the reason you are here, the free plan will not get you there.

How strict are the usage limits?

The pricing page states that usage limits apply and that prices and plans can change at Anthropic's discretion, without publishing a per-hour number on that page. That is why the advice above is to run a normal working month on Pro and record when you get stopped, rather than guess at a ceiling in advance.

Do I need to be a developer to get value?

For this tool, mostly yes. It works inside real projects and assumes you can review what it changed. If your goal is a finished website or a small app rather than a coding workflow, a one-shot builder such as Begin.sh gets you there without installing anything or learning a new loop.

Can I pay monthly instead of annually?

Yes. The listed monthly rate for Pro is twenty dollars, against seventeen if you take the annual option at two hundred dollars up front. The site describes the plans as no commitment and cancellable at any time, which makes the monthly rate a sensible way to run the one-month test described above.

Is this the official Claude page?

No. This is an independent write-up by a paying user. Every figure quoted here was read off the vendor's own public pricing page and may have moved since; check the official link before you buy, especially for anything billed annually.
